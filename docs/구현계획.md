# 구현 계획

기준 문서: `시흥제일교회_영유아교회_PRD.md` v1.0. 구현 전에 채팅으로 다음 계획을 안내했습니다.

1. 공개 5개·비공개 2개 화면과 별도 관리자 운영 화면을 만듭니다.
2. 데이터·권한 → 공개 화면 → 비공개 공간 → 관리자·업로드 → 검증 → 운영 안내 순서로 진행합니다.
3. 콘텐츠와 파일을 Supabase에 저장하고 초안·검토자·수정자·수정 버전을 기록합니다.
4. 공용 비밀번호는 scrypt 해시로만 보관하고, 공간별 세션·페이지·파일의 서버 권한을 검사합니다.
5. 12시간 세션, 최대 5분 이내 파일 링크(구현값 60초), 홈 각 3개, 자료 20MB, 사진 10MB, 한국 시간을 사용합니다.
6. 실제 예배 정보·성경·교리·사진을 만들지 않습니다. 미입력 정보는 준비 중/빈 상태로 표시합니다.
7. Supabase 계정 개설·예산·관리자 초대·비밀번호·실제 공개 배포는 운영 설정으로 분리합니다.

추가 요청에 따라 고정 최대 폭 중심 배치에서 유동형 배치로 변경했습니다. 기본 외곽 여백은 `clamp(20px, 5vw, 110px)`이며 카드와 제목도 화면 폭에 맞춰 변합니다. 긴 본문은 읽기 편한 폭을 유지합니다.

추가 요청: GitHub 공개 저장소 생성·소스 업로드. 실제 자격 증명과 업로드 자료는 포함하지 않습니다.
